# BookVerse Redux + MongoDB Project

Phase 1 and 2 implementation with backend APIs and Redux Toolkit integration.

## Redux Concepts
- Store
- Slice
- Reducers
- Actions
- Async Thunks
- Selectors
- Global State

## MongoDB Concepts
- Compound Indexes
- Text Indexes
- Referencing
- Aggregation
